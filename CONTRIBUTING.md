# Contributing

Thanks for your interest. This repository accompanies a published article, so the analysis is kept stable; corrections and clarifications are welcome.

- **Questions or bugs:** open an issue using the templates provided.
- **Pull requests:** keep them small and focused (documentation fixes, bug fixes). Describe what changed and why.
- **Data:** never commit participant data or generated results (`data/` and `output/` are git-ignored).
- **Methods changes** that would alter published results should be discussed in an issue first.
